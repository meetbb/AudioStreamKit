## Important Design Decisions Made

- V1 scope: streaming + playback + basic caching only; download/offline is
  a later milestone.
- V1 is single-item playback only (no queue/playlist); progressive
  HTTP(S) download only (no HLS in V1).
- Interruption resume policy: auto-resume only if playback was active
  immediately before the interruption.
- Resource loading: intercept via `AVAssetResourceLoaderDelegate` rather
  than letting AVPlayer stream directly (ADR-001).
- Retry policy: hand-rolled locally rather than depending on
  SwiftResilience (ADR-002).
- Convert the project to an SPM package (not yet done — planning only).

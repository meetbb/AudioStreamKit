# 2026-09-11

## Goal
Plan V1 scope and architecture for AudioStreamKit, then start writing the first real code.

## What Happened
- Reviewed the empty starter project and the user's separate networking library (SwiftResilience) to decide what AudioStreamKit should own vs. reuse.
- Found working test audio streams to use for development (no backend exists yet).
- Agreed on V1 scope: streaming + playback + basic caching only. No playlists, no offline downloads, no HLS yet.
- Converted the project from a plain Xcode project to a Swift Package (iOS 17 minimum), moved files into standard `Sources/`/`Tests/` folders, and confirmed it builds and tests pass.
- Designed and documented four architecture pieces (all in `Documentation/architecture/`): the playback state machine, the public API, the concurrency model, and error handling. First two are Accepted; the last two are still Proposed (not yet confirmed with user).
- Wrote two ADRs explaining key decisions (how media loading works, why retries are hand-rolled instead of using SwiftResilience).
- Started real implementation: `PlaybackError`, `PlaybackState`, `PlaybackEvent`, `PlaybackStateMachine`, `RetryPolicy`, and `FailureClassifier` now have working code. Everything else is still an empty placeholder.

## Decisions Made
- Single-item playback only in V1 (no queue).
- Auto-resume after interruption only if playback was active right before it.
- Media loading is intercepted manually (`AVAssetResourceLoaderDelegate`) rather than left to AVPlayer (see ADR-001).
- Retry logic is custom, not from SwiftResilience (see ADR-002).

## Open Questions
- Should retry limits be counted per-item or per-byte-range? (affects `MediaSource`, not yet built)
- Should `concurrency-model.md` and `error-handling-strategy.md` be reviewed and Accepted?
- `FailureClassifier` can't yet tell a decode failure from an unsupported format — placeholder until `MediaSource` exists.
- A couple of smaller open items live in each architecture doc's own "Open Questions" section — check there for details if needed.

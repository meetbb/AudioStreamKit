# 2026-09-13

## Changed
- Implemented `MediaSource`: `AVAssetResourceLoaderDelegate` on a dedicated
  serial queue, URL scheme rewriting (`https`/`http` <-> custom scheme),
  item-scoped retry via `RetryPolicy`/`FailureClassifier`, and cancellation
  tracking per loading request.
- Implemented `MediaCache`: SHA-256 cache keys, per-key sparse data file +
  JSON metadata sidecar (survives relaunch), missing-range diffing,
  ordered writes (bytes durable before marked present), an offset-explicit
  read plan, and LRU eviction bounded by cache size.
- Wired `MediaCache` into `MediaSource`. `contentInformationRequest`
  answers from cache when available, otherwise probes the origin (HEAD,
  ranged-GET fallback) and stores the result. `dataRequest` diffs the
  requested range against the cache and responds segment by segment —
  cache hits read from disk, gaps are fetched with retry and written
  through best-effort.
- `Package.swift`: added a macOS platform floor so the package builds on
  a Mac.
- Accepted the concurrency model and error-handling architecture docs.
  Retry budget is item-scoped, not per byte-range.

## Decisions
- Retry budget: item-scoped (one rolling counter per loaded item, reset on
  success), not per byte-range.
- Cache write failures never fail playback — they degrade to serving the
  network bytes already fetched, uncached.
- ETag/Last-Modified are captured and stored per cached item, but not yet
  used to revalidate — an entry is trusted indefinitely once cached.

## Known limitations
- No revalidation policy yet: a cached item is never checked against the
  origin for staleness.
- No tests yet for `contentInformationRequest`/`dataRequest`/the retry
  loop directly — needs a real asset or local server to drive it, not a
  plain unit test. The range-tiling logic behind `dataRequest` is unit
  tested on its own.
- Eviction only considers entries touched since the cache was created in
  the current process, not everything ever persisted to disk.
- Failure classification for asset-layer errors is still a placeholder
  (always maps to a generic decode failure).
